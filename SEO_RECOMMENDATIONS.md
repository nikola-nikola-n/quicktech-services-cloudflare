# Google SEO Starter Guide - Key Recommendations for QuickTech Services

## Overview
The SEO Starter Guide outlines essential practices to help Google understand your content and improve your site's visibility in search results. Following these recommendations increases the likelihood of appearing in Google Search results.

## Key Areas from Google's Guide

### 1. Help Google Find Your Content
- **Sitemap**: Submit a sitemap file containing all URLs you want indexed (QuickTech Services already has sitemap1.xml)
- **Links**: Other websites linking to your pages helps Google discover content naturally
- **Promotion**: Encourage people to discover your content through legitimate promotion

### 2. Ensure Google Can See Your Pages Correctly
- Google should see pages the same way users do
- Ensure CSS and JavaScript resources are accessible to Google's crawlers
- Use URL Inspection Tool in Search Console to verify how Google sees your pages
- Consider user location - Google crawls from the US primarily

### 3. Organize Your Site Logically
- **Descriptive URLs**: Use meaningful words in URLs (e.g., `/greenslopes` instead of `/2/6772`)
- **Directory Structure**: Group similar content in directories to help Google understand crawl frequency
- **Breadcrumbs**: URLs displayed as breadcrumbs in search results help users understand context

### 4. Handle Duplicate Content
- Specify canonical URLs to indicate the preferred version of content
- Google will try to canonicalize automatically, but explicit specification is better
- Duplicate content wastes crawling resources and can hurt user experience

### 5. Create Helpful, Reliable Content
- Focus on people-first content that serves user needs
- Avoid keyword stuffing (against Google spam policies)
- Google doesn't use the keywords meta tag - focus on actual content quality

### 6. Technical Requirements
- Ensure site meets technical requirements for indexing
- Check Search Console for crawling and indexing issues
- Use robots.txt and meta tags to control what appears in search results

### 7. Metadata & Rich Snippets
- Write descriptive title tags (displayed in search results)
- Write good meta descriptions (displayed below title in results)
- Use structured data (schema markup) for breadcrumbs, local business info, etc.
- Add good alt text to images for accessibility and image search

### 8. Links & Anchor Text
- Use appropriate, descriptive anchor text for links
- Use nofollow for untrusted links
- Internal linking helps Google understand site structure

### 9. Site Speed & Performance
- Page speed is a ranking factor
- Optimize images and resources
- Minimize CSS/JavaScript where possible
